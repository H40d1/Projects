Cómo hacer funcionar el proyecto paso a paso ################################
# ---------------------------------------------------------------------------------------------------------- #
# 1. Sitúese en el directorio raíz del proyecto.							     #
#    Si ha abierto este fichero desde la ruta en la que se encuentra, ya está situado sobre dicho directorio #
# 2. Abra una ventana de terminal en esta ruta. Varía para cada Sistema Operativo y para cada distribución   #
# 3. Realice el siguiente paso en función del SO que esté utilizando:					     #
#	- Si está utilizando una terminal UNIX o derivados, lance el mandato 'python .\src\practica203.py'   #
#       - Si está utilizando una terminal MS-DOS, lance el mandato 'python src\practica203.py'               #
#    Para ambos casos se habrá lanzado una ventana gráfica, que hará funcionar nuestra práctica.             #
# 4. Para finalizar la ejecución puede simplemente cerrar la ventana o matar al proceso desde la propia      #
#    línea de mandatos (generalmente Ctrl + C)                                                               #
# 													     #
#													     #
#													     #
# Tenga en cuenta que, para poder hacer funcionar este proyecto, es condición necesaria tener instalado      #
# Python en su equipo.											     #
